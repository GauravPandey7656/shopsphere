# ShopSphere

A modern e-commerce web application built with React, React Router, Tailwind CSS, and Vite.

ShopSphere provides a complete shopping experience with product browsing, authentication, cart management, wishlist functionality, checkout, order history, and product reviews.

## Features

- User signup and login
- Multiple user account support
- User profile management
- Product listing and product details
- Product search and filtering
- Category and price filtering
- Product sorting
- Shopping cart management
- Wishlist management
- Checkout flow
- Order history
- Product reviews
- Review deletion for review owners
- Protected routes for authenticated users
- Public/private route handling
- Loading and error states
- Responsive user interface
- Persistent data using browser localStorage

## Tech Stack

### Frontend
- React
- React Router
- Tailwind CSS
- Vite
- JavaScript (ES6+)

### Development & Quality
- ESLint
- Git
- GitHub

### Data
- DummyJSON Products API
- Browser localStorage for application state persistence
